TUKISO (PTY) LTD WEBSITE STARTER

FILES
- index.html: website content and sections
- style.css: colours, layout, fonts and responsive design
- images/tukiso-logo.jpeg: your supplied company logo

HOW TO OPEN
1. Extract this ZIP file.
2. Open the TUKISO-PTY-LTD-WEBSITE folder in Visual Studio Code.
3. Open index.html.
4. Right-click and choose Open with Live Server (if Live Server is installed), or open index.html in your browser.

IMPORTANT CUSTOMISATION
- Replace the example service categories with TUKISO's real services.
- Replace project names and descriptions with genuine company projects.
- Replace phone, email and address placeholders.
- Change info@yourcompany.co.za in the form action to the company's actual email.
- The sample form uses mailto and is not a database-backed online form.
- Internet connection is required for the remote sample background images and Google Fonts.
